# DiceZone 骰子之间

> 面向文字跑团与聊天机器人的开源软件项目  
> Open-source software for text-based tabletop role-playing games and chatbots.

## 关于 | About

DiceZone 的主要项目包括 **Dice!Next** 和 **CatOfficial**。Dice!Next 是经典跑团骰子机器人 Dice! 的跨平台重构，提供掷骰、人物卡管理、跑团日志和 Web 管理面板。CatOfficial 将 QQ 官方机器人接口转换为标准 OneBot v11 接口，供支持该协议的应用接入 QQ 官方平台。

DiceZone’s main projects include **Dice!Next** and **CatOfficial**. Dice!Next is a cross-platform rewrite of the Dice! TRPG bot, with dice rolling, character sheets, session logs, and a web administration panel. CatOfficial exposes the official QQ Bot API through a standard OneBot v11 interface for compatible applications.
